# Findings

A finding is a measured observation about a BAFU dataset or release: an amount that cannot be right, a supplier that does not resolve, a flow the flow list does not carry. Each finding is measured on BAFU's own release files, has a record, and links to the issue or thread where it is discussed.

Findings are reported to BAFU, and BAFU decides what it changes. A community patch can apply a correction in the [patched release](import.md) for those who need it now. A proposed model or a method variant is not a finding; it is a [contribution](../community/workflow.md).
